# Winsight v0.2.2 - 2026-11-19

*[English release notes](../../release-notes-v0.2.2.md)*

Version corrective résolvant le diff des observations filtrées, le drapeau
`truncated` et l'activation des barres de menus Win32 personnalisées observés
lors des tests terrain sur VMware Workstation (`vmware.exe`, `wui.unibar`).

## Corrections

- `act_verified` avec `expect.kind=any_change` (ainsi que `observeAfter=true`
  et les captures de reprise) réutilise désormais exactement les filtres de
  l'observation source (`windowTitle`, `maxResults`, `actionableOnly`,
  `filterText`, `includeOcr`). Une observation filtrée suivie d'une action sans
  effet ne produit plus de faux `elementsAdded` ni de faux `verified`.
- `observe_scene` applique désormais `filterText` et `actionableOnly` sur tout
  l'arbre UIA parcouru avant d'appliquer le plafond `maxResults`. `truncated`
  vaut `true` uniquement si les résultats correspondants ont été coupés par
  `maxResults` ou si le parcours UIA a atteint sa limite (`10000` noeuds) ou une
  `COMException`.
- `act_verified` avec `action=activate` sur un `MenuItem` et
  `expect.kind=any_change` exige désormais une preuve réelle d'ouverture de menu
  (nouvelle fenêtre/popup, nouveaux éléments `Menu`/`MenuItem`/`MenuBar` absents
  de la capture non filtrée précédente, ou transition du `MenuItem` vers
  `Expanded` / `PartiallyExpanded`). Si aucun menu ne s'ouvre avant expiration
  (cas courant sur les barres de menus Win32 personnalisées comme `wui.unibar`
  qui ignorent UIA `Invoke`), `act_verified` renvoie `dispatched_unconfirmed`
  avec un indice structuré `click_point` centré sur les bornes de l'élément.

## Installation

**Recommandé :** télécharger et lancer `Winsight-Setup-0.2.2-win-x64.exe`
(assistant anglais/français sans droits administrateur pour Codex, Claude
Desktop, Claude Code et Gemini CLI).

Pour la version portable, télécharger `winsight-0.2.2-win-x64.zip` et
`SHA256SUMS.txt`, vérifier l'empreinte SHA-256 avec
`Get-FileHash -Algorithm SHA256`, extraire tous les fichiers dans un dossier
dédié et pointer le client MCP sur `winsight-mcp.exe`.
