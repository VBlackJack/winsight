Winsight est prêt à vous aider

Winsight permet à votre assistant d’inspecter et de piloter vos applications Windows.

Installation en trois étapes

  1. Fermez Codex, Claude Desktop, Claude Code et Gemini CLI.
  2. Lancez Winsight Setup, puis cochez les applications que vous utilisez.
  3. Rouvrez ces applications et acceptez la connexion à Winsight si elles vous le demandent.

Aucune commande, clé API ou installation de .NET n’est nécessaire pour les outils de base. Les applications clientes doivent déjà être installées. Le setup détecte leurs dossiers de configuration ; vous pouvez aussi cocher manuellement une application.

Votre première demande

Demandez : « Avec Winsight, liste les fenêtres ouvertes. » Vous pourrez ensuite désigner l’application à inspecter. Les autorisations restent contrôlées par votre assistant.

Modifier ou désinstaller

Relancez le setup pour connecter une autre application. Pour retirer Winsight, utilisez Paramètres Windows → Applications → Winsight → Désinstaller. Seules les connexions qui pointent encore vers cette installation sont retirées.

Si la configuration échoue

Fermez vos assistants puis relancez le setup. Si une ancienne connexion Winsight existe, retirez-la dans les réglages MCP de l’assistant avant de réessayer. Le setup ne la remplace pas automatiquement. Les sauvegardes .winsight-….bak restent à côté des fichiers de configuration ; les journaux sont dans %LOCALAPPDATA%\Winsight\logs.

La reconnaissance visuelle par modèle est facultative et nécessite une configuration supplémentaire, décrite dans la référence des outils.

English quick start

Close your clients, run Winsight Setup, select Codex, Claude Desktop, Claude Code and/or Gemini CLI, then restart them. No terminal command or .NET installation is required. Ask your assistant to list open windows with Winsight. Rerun setup to add a client. Uninstall through Windows Settings. Existing conflicting Winsight registrations are preserved: remove them in the client's MCP settings before retrying. Backups remain beside client settings.
